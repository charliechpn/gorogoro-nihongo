# Study data sources and attribution

The study catalogs and translations in this repository include derivatives of [OpenJLPT](https://github.com/evanclan/OpenJLPT), which publishes its dataset under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Changes in this project include Portuguese and English editorial curation, selected practice categories, and revised explanations. The derived data is distributed under the same CC BY-SA 4.0 terms.

OpenJLPT draws on these upstream sources:

| Source | Contribution | License / terms |
| --- | --- | --- |
| [EDRDG JMdict / EDICT](https://www.edrdg.org/) | Vocabulary readings and glosses | [EDRDG licence](https://www.edrdg.org/edrdg/licence.html); CC BY-SA 4.0 as incorporated by OpenJLPT |
| [EDRDG KANJIDIC2](https://www.edrdg.org/wiki/KANJIDIC_Project.html) | Kanji readings, meanings, and metadata | [EDRDG licence](https://www.edrdg.org/edrdg/licence.html); CC BY-SA 4.0 as incorporated by OpenJLPT |
| [Jonathan Waller's JLPT resources](https://www.tanos.co.uk/jlpt/) | Unofficial N5–N1 groupings | CC BY, as credited by OpenJLPT |
| [Tatoeba](https://tatoeba.org/) | Example sentences in source data | [CC BY 2.0 FR](https://creativecommons.org/licenses/by/2.0/fr/) |

The original OpenJLPT notice is preserved at [`kanjis/kanji database 1 - openjlpt.NOTICE.md`](kanjis/kanji%20database%201%20-%20openjlpt.NOTICE.md). Please retain both that notice and this file when redistributing the derived data. JLPT level lists here are unofficial approximations; the JLPT does not publish official vocabulary or kanji lists for N5–N1.
